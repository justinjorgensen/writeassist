# Author Rules - Living Constraints & Creative Contract

> This is your project's manifesto and constraint set. It defines what you MUST do, what you MUST NOT do, and WHY.
> AI agents check this file FIRST before any creative task. Update it when you learn from mistakes or make new decisions.

---

## 🚫 HARD CONSTRAINTS (Never Break These)

### Narrative Structure
- **NO head-hopping** - Maintain strict POV within scenes
- **NO deus ex machina** - All resolutions must be properly set up
- **NO info-dumping** - Weave backstory naturally through action/dialogue
- **NO coincidence resolutions** - Solutions must come from character agency
- **NO POV character deaths** without proper foreshadowing and purpose

### Style & Voice
- **NO EM DASHES EVER** - Use commas, colons, or parentheses instead. ZERO TOLERANCE.
- **NO modern slang** in historical/fantasy settings
- **NO purple prose** - Clear, powerful writing over flowery description
- **NO filter words** - Cut "she saw," "he felt," "they heard"
- **NO passive voice** in action scenes
- **NO telling emotions** - Show through action, dialogue, physicality

### Character Rules
- **NO perfect protagonists** - Every character needs flaws
- **NO one-dimensional villains** - Antagonists need understandable motivations
- **NO instant expertise** - Skills require established training/experience
- **NO personality reversals** without traumatic cause
- **NO forgotten injuries/trauma** - Maintain consequences

---

## ⚠️ SOFT CONSTRAINTS (Avoid Unless Justified)

### Common Pitfalls
- **AVOID dream sequences** - Overdone, usually meaningless
- **AVOID mirror descriptions** - Find creative ways to describe characters
- **AVOID weather openings** - Start with character/conflict instead
- **AVOID prophecies** - Unless subverted meaningfully
- **AVOID chosen one tropes** - Unless deconstructed

### Pacing Guidelines
- **LIMIT flashbacks** to 1 per 3 chapters maximum
- **LIMIT internal monologue** to 2 paragraphs at a time
- **LIMIT description blocks** to 150 words
- **MINIMIZE dialect spelling** - Use rhythm/vocabulary instead
- **REDUCE adverbs** - Use stronger verbs

## ✅ MANDATES (Always Do These)

### Technical Requirements
- **MAINTAIN consistent POV** - [Specify: first/third limited/omniscient]
- **MAINTAIN consistent tense** - [Specify: past/present]
- **USE Oxford commas** consistently
- **USE chapter hooks** - Every chapter ends with momentum
- **FOLLOW genre conventions** while adding fresh elements

### Story Craft
- **GROUND every scene** in sensory details within first paragraph
- **ESTABLISH setting** immediately when location changes
- **GIVE every scene** a clear purpose (advance plot/reveal character)
- **CREATE conflict** in every scene (external or internal)
- **SHOW character change** through actions, not declarations

### Character Development
- **DISTINGUISH character voices** through vocabulary/rhythm/concerns
- **TRACK character arcs** across chapters
- **MAINTAIN character knowledge** - They only know what they've learned
- **RESPECT character limitations** - Physical, emotional, intellectual
- **BUILD relationships** gradually and believably
