## Performance & Requirements

### System Requirements
- Multiple chapters or WRPs to process
- Populated story-compendium.md
- Configured author-rules.md (em dash ban!)
- Clear outline.md for WRP generation
- 02-Manuscript/ directory structure

### Performance Tips
1. Run large batches during breaks
2. Use parallel mode for faster processing
3. Start with small test batch
4. Review reports between stages
5. Keep backups (automatic)
6. Watch for em dash elimination confirmations

### Processing Times
- WRP Generation: ~2 min/chapter
- Chapter Writing: ~3-4 min/chapter
- Review & Fix: ~1.5 min/chapter
- **Total: ~6-7 minutes per chapter**
