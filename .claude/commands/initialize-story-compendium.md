# initialize-story-compendium

**No-argument behavior:** Takes no arguments; interviews the author for initial content.

Set up your story compendium with all essential components for your book project.

## Command Purpose
Create and populate the master story-compendium.md with structured sections for tracking all story elements. This is your first command after project setup.

## What Gets Created

### Core Sections
1. **Project Metadata**
   - Title, genre, target audience
   - Word count goals
   - Tone and style guidelines

2. **Characters**
   - Protagonist profiles
   - Antagonist profiles  
   - Supporting cast
   - Character relationships map

3. **World Building**
   - Settings and locations
   - Rules and systems
   - Culture and society
   - Technology/magic level

4. **Plot Structure**
   - Premise and logline
   - Three-act breakdown
   - Major plot points
   - Subplots tracking

5. **Timeline**
   - Chronological events
   - Character ages at key points
   - Historical backdrop
   - Future implications

6. **Themes & Symbols**
   - Core themes
   - Recurring symbols
   - Motifs and patterns
   - Message/meaning

## Usage

```bash
"Initialize story compendium for [genre] novel"
```

## Interactive Setup

The command will prompt for:
- Book title
- Genre and subgenre
- Target audience
- Estimated length
- Number of POV characters
- Setting (time/place)
- Core conflict

## AI Agents Activated

1. **story-architect** - Structure design
2. **world-builder** - Setting creation
3. **character-developer** - Character templates
4. **thematic-guide** - Theme integration

## Output Files

- `story-compendium.md` - Master reference
- `01-Planning/initial-concept.md` - Original vision
- `04-Project-Management/style-guide.md` - Writing style rules

## Next Steps

After initialization:
1. Run `create-character` for each major character
2. Run `outline-book` to structure chapters
3. Run `update-timeline` to refine chronology

## Tips

- Be thorough but not rigid - this document evolves
- Include "Unknown" sections for later development
- Add reference images/links where helpful
- Update after each writing session
