## Foreshadowing Balance

### The Goldilocks Principle
- **Too Much**: Twist becomes predictable
- **Too Little**: Feels like cheating
- **Just Right**: Surprising but inevitable

### Clue Visibility Levels
1. **Invisible**: Only clear in hindsight
2. **Subtle**: Noticeable if looking
3. **Hidden**: Disguised as something else
4. **Apparent**: Clear but misinterpreted
5. **False**: Intentional misdirection

## Red Herring Management

### Effective Red Herrings
- Plausible alternatives
- Logical motivation
- Supporting evidence
- Reader investment
- Clean resolution

### Red Herring Types
- False villain
- Wrong solution
- Misunderstood event
- Coincidental evidence
- Mistaken identity

## Twist Quality Checkers

### The Four Tests
1. **Surprise Test**: Did NOT see it coming
2. **Logic Test**: Makes perfect sense
3. **Hindsight Test**: Clues were there
4. **Satisfaction Test**: Feels earned

### Common Pitfalls
- Deus ex machina solutions
- Withholding POV information
- Contradicting established facts
- Multiple personality cop-outs
- It was all a dream
- Coincidence resolutions

## Multi-Layer Twists

### Cascade Structure
1. Initial twist reveals truth
2. Truth leads to bigger question
3. Bigger question reveals deeper twist
4. Final twist recontextualizes everything

### Example Cascade

- Twist 3: From protagonist's real identity

## Best Practices

1. Plan twists from start
2. Work backwards from reveal
3. Plant 3+ clues minimum
4. Test on beta readers
5. Ensure emotional payoff
6. Make inevitable in hindsight
7. Avoid twist fatigue
8. Respect reader intelligence
