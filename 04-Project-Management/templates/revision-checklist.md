# Revision Checklist

## Big Picture Review

### Story Structure
- [ ] Three-act structure clear
- [ ] Inciting incident compelling
- [ ] Rising action builds properly
- [ ] Climax satisfying
- [ ] Resolution complete
- [ ] Subplots resolved

### Character Development  
- [ ] Protagonist arc complete
- [ ] Antagonist motivations clear
- [ ] Supporting characters serve purpose
- [ ] Character growth shown not told
- [ ] Relationships evolve naturally
- [ ] All POVs necessary

### Theme & Meaning
- [ ] Central theme clear
- [ ] Theme emerges from story
- [ ] Not heavy-handed
- [ ] Symbols support theme
- [ ] Message resonates

## Chapter Level Review

### For Each Chapter Check:
- [ ] Opens with hook
- [ ] Advances plot
- [ ] Develops character
- [ ] Maintains tension
- [ ] Ends with momentum
- [ ] POV consistent
- [ ] Timeline accurate
- [ ] Word count appropriate

## Scene Level Review

### Scene Effectiveness
- [ ] Each scene has purpose
- [ ] Conflict present
- [ ] Stakes clear
- [ ] Emotion conveyed
- [ ] Setting established
- [ ] Sensory details included

### Dialogue Quality
- [ ] Sounds natural
- [ ] Characters distinct
- [ ] Advances plot
- [ ] Reveals character
- [ ] Subtext present
- [ ] Attribution clear

## Line Level Review

### Prose Quality
- [ ] Sentences varied
- [ ] Active voice dominant
- [ ] Strong verbs used
- [ ] Clichés eliminated
- [ ] Purple prose cut
- [ ] Clarity maintained

### Technical Accuracy
- [ ] Grammar correct
- [ ] Spelling checked
- [ ] Punctuation proper
- [ ] Formatting consistent
- [ ] Facts verified
- [ ] Continuity maintained

## Pacing Review

### Story Rhythm
- [ ] Opening engages quickly
- [ ] Middle maintains interest
- [ ] Climax properly paced
- [ ] Quiet moments balanced
- [ ] Page-turner quality
- [ ] Natural break points

## Consistency Review

### Continuity Checks
- [ ] Character descriptions
- [ ] Timeline/chronology
- [ ] Geography/distances
- [ ] Weather/seasons
- [ ] Technology/magic rules
- [ ] Names/spellings

## Market Readiness

### Genre Expectations
- [ ] Meets genre conventions
- [ ] Target audience appropriate
- [ ] Comparable titles identified
- [ ] Unique elements clear
- [ ] Hook marketable
- [ ] Length appropriate

### Professional Polish
- [ ] Title compelling
- [ ] First page stellar
- [ ] First chapter hooks
- [ ] Last page satisfies
- [ ] Synopsis ready
- [ ] Query letter prepared

## Beta Reader Feedback

### Common Issues to Address
- [ ] Confusing passages clarified
- [ ] Slow sections tightened
- [ ] Character motivations strengthened
- [ ] Plot holes filled
- [ ] Emotional moments enhanced
- [ ] Ending satisfaction improved

## Final Review

### Last Checks
- [ ] Read entire manuscript aloud
- [ ] Fresh eyes review
- [ ] Professional proofread
- [ ] Format requirements met
- [ ] Backup created
- [ ] Version control updated
